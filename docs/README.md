# Архитектурное ТЗ CRM/ERP

Документ разделён на две связанные части:

1. [ARCHITECTURE.md](./ARCHITECTURE.md) — архитектурные решения, структура проекта, модули и подробная ER-модель.
2. [ACCESS-WORKFLOWS.md](./ACCESS-WORKFLOWS.md) — RBAC, области данных, автомат статусов, склад, калькулятор, API, безопасность, аналитика, тестирование, этапы, риски и открытые решения.

Обе части составляют единое архитектурное техническое задание версии 1.0. Это не реализация приложения и не разрешение начинать массовый CRUD: перед кодированием необходимо согласовать решения из раздела 17 второй части и оформить их ADR.
